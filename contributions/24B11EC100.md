## Three Git Commands and Their Uses

1. `git status` — Shows the current state of the working directory and staged changes.
2. `git add .` — Stages all changes in the current directory for the next commit.
3. `git commit -m "message"` — Saves staged changes as a commit with a descriptive message.

## Purpose of GitHub

GitHub is an online platform used to store, manage, and share code repositories. It helps developers collaborate on projects, track changes, review code, and maintain project history.

## One Benefit of Using Branches

Branches allow developers to work on new features or make changes separately without affecting the main branch. This makes collaboration safer and helps keep the main project stable.
